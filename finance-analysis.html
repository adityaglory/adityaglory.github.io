RNN and Transformer Models for Financial Sentiment Analysis Under Hardware Constraints

By Glory Aditya Jauzaulbahi

Abstract

Financial news sentiment analysis is a critical component in algorithmic trading, yet datasets often suffer from extreme class imbalance and domain-specific lexical noise. Furthermore, fine-tuning state-of-the-art Natural Language Processing (NLP) models on consumer-grade hardware poses significant memory constraints. This study presents an end-to-end pipeline to address these challenges using the Financial PhraseBank dataset by applying Random Oversampling and custom stopword filtering. We benchmarked three distinct architectures—a highly tuned classical BiLSTM, a lightweight MobileBERT, and a complex DeBERTa-v3—on a strictly limited local device (8GB VRAM). The empirical results demonstrate that Google's MobileBERT outperformed the others with a Macro F1-Score of 0.99 and flawless real-world inference. This study proves that utilizing lightweight transformers yields superior performance in edge-computing environments compared to the indiscriminate adoption of massive architectures.

1. Introduction

Amidst the massive wave of digitalization, financial information moves within seconds across various platforms. Real-world observations indicate that economic narratives in financial news are fraught with extreme ambiguity, where a single term can trigger completely opposing interpretations depending on prevailing market conditions. This uncertainty-laden complexity renders financial news data highly nuanced, meaning it cannot be comprehended literally and demands deep, contextual interpretation.

A critical dimension of this exploration involves balancing the need for advanced semantic interpretation with practical deployment constraints. While previous studies prioritize maximizing evaluation metrics via massive architectures like FinBERT [2], [3], a noticeable gap exists regarding the practical deployment of these deep models in highly resource-constrained edge environments. This study uniquely emphasizes the engineering challenges of hardware instability and Mode Collapse when benchmarking memory-efficient transformers against State-of-the-Art (SOTA) models under a strict 8GB VRAM limitation.

2. Methodology

2.1. Dataset and Preprocessing

The primary data source for this study is the Financial PhraseBank dataset [1], categorized into Negative, Neutral, and Positive sentiments. Initial exploratory data analysis revealed a severe class imbalance, heavily dominated by the "Neutral" class (1,391 samples) while the "Negative" class was severely underrepresented (303 samples).

To mitigate the risk of mode collapse, Random Oversampling was applied to the minority classes, duplicating random instances until they matched the Neutral class volume (1,391 samples each). Lexical extraction was also performed to filter out domain-specific stopwords (e.g., profit, million, euro). To optimize memory overhead, the sequence maximum length threshold was strictly set to 128 tokens, which was sufficient to encapsulate over 99% of the sentence contexts.

3. Model Architectures & Experimental Setup

All experiments were strictly executed locally on a consumer-grade NVIDIA RTX 3070 GPU (8GB VRAM limit). To prevent Out-Of-Memory (OOM) fragmentation, aggressive memory management—including explicit garbage collection and manual CUDA cache clearing—was enforced. The three evaluated models were:

  • BiLSTM: Serving as the classical sequential baseline, augmented with frozen pre-trained BERT embeddings, Batch Normalization, and optimized via RMSprop with a ReduceLROnPlateau scheduler [6].
  • MobileBERT: A thin, memory-efficient version of BERT_LARGE optimized for edge devices [7]. Fine-tuned using a standard learning rate of 2e-5 and Early Stopping.
  • DeBERTa-v3: A SOTA architecture utilizing a disentangled attention mechanism [8]. It required extreme stabilization (learning rate 1e-5, weight decay 0.05, warmup 150 steps, and AdamW) simply to force the model to complete the training loop without hardware failure.

4. Results and Discussion

4.1. Model Evaluation Metrics

Evaluated strictly on an unseen, stratified Test Set (418 samples), the selected architectures demonstrated vastly different proficiencies. The classical baseline, BiLSTM, established a remarkably robust foundation (Macro F1: 0.94) but struggled with the sequential nuances between Neutral and Positive classes.

4.2. Diagnostic Analysis and Mode Collapse

MobileBERT's self-attention mechanism effectively captured long-range dependencies while remaining highly optimized for the 8GB VRAM constraint. The RNN-based BiLSTM model fell victim to semantic traps; constrained by its left-to-right processing, it mistakenly classified complex negative statements as positive because it missed trailing negative context.

Most notably, the SOTA DeBERTa-v3 model failed completely under hardware deprivation, suffering a catastrophic Mode Collapse (Macro F1: 0.17). Regardless of the input, the model stubbornly outputted the "Negative" class. Its complex disentangled attention mechanism demanded massive memory buffers, causing the optimizer to fail and settle into a mathematical dead end.

5. Conclusion

This study successfully engineered an end-to-end financial sentiment analysis pipeline tailored for resource-constrained hardware. The empirical evaluation challenges the prevailing trend of indiscriminately utilizing massive architectures. We proved that adopting complex SOTA models like DeBERTa-v3 in edge-computing environments is an anti-pattern. Conversely, Google's MobileBERT emerged as the optimal solution, flawlessly bypassing hardware constraints to achieve a remarkable 0.99 Macro F1-Score, proving that lightweight transformers deliver the most robust solution for local algorithmic trading systems.
